The Project is about using AI and Laser technology for weeds elimination in a tomato Farm.
Trained a CNN model and YOLO models for deployment in Raspberry PI microcontroler.
CNN models not good enough to tell the exact location of an object in a camera field of view.
On the other hand YOLO wins by pointing out the position of an object by use of bounding boxes.
For precision, YOLO proved to be the best.
Also trained YOLO V8 and YOLO V9 models to see which would work well with the micro-controller.
For more info see my Ptechnical paper on the comparison: https://www.researchgate.net/publication/407295708_Title_CHOICE_OF_YOLO_A_MODEL_YOLOv8_and_YOLOv11n_Performance_on_RasberryPI
